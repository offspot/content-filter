The content-filter allows you to block certain URLs on your server. You can only block URLs served by your own server.

Blocking is effective immediately. Simply navigate to the URL you want to block, and copy-paste it into the content-filter.

You might have to use refresh to see the change.

Export to file

You can export your blocked URLs list into a standard JSON file.
This can be used as backup or to copy into another installation.

Export All

Import from file

Importing URLs from a previously exported file. URLs from your existing block list won't be removed.

Delete all URLs

Remove all blocked URLs from your list. This action cannot be undone.
